# Reproduction checks

All 12 experiment groups completed full runs in a clean CPU environment on
2026-11-17. They were executed in three batches, rather than one uninterrupted
`--groups all` invocation:

```bash
python scripts/run_experiments.py --groups alignment,allocation,xavier --output results
python scripts/run_experiments.py --groups sampling,dataset_size,scale,initialization,inputs,nonlinear --output results
python scripts/run_experiments.py --groups rate,anisotropic,noise --output results
```

The generated results were then used to regenerate every final-paper table and
figure:

```bash
python scripts/make_tables.py --data-dir results --output build/fresh/tables
python scripts/verify_tables.py --tables-dir build/fresh/tables
python scripts/make_figures.py --data-dir results --output build/fresh/figures
```

Results:

- All five tables match the independently extracted final-paper snapshot:
  **68 rows and 400 numeric entries**, including the new Xavier normal control.
- All five vector PDFs (Figure 2a, Figure 2b, Figure 3, Figure 4, Figure 5)
  generated from fresh results are byte-identical to PDFs generated by the same
  script from the saved reference results.
- The main experiments and Xavier control match the reference data exactly
  across **80 raw arrays**.
- Figure 4's fitting/alignment counts and allocation errors agree with the
  references. All **288 plotted Figure 5 values** agree within `1e-9`; the maximum
  difference is below `7e-15`. The full noisy-label summary also agrees across
  **4,080 diagnostic values**, with maximum difference below `1.8e-14`.
- The float32 initialization ablation has small full-precision differences in
  the newer runtime. Its largest unrounded table-aggregate difference is
  `9.17546e-6` radians. Every printed Table 2 value is unchanged, and fitting
  status, fitting checkpoints and changed-sign fractions match exactly for all
  300 reported original initialization runs. This is agreement at the paper's
  displayed precision, not bitwise equality of those float32 diagnostics.

`full_suite_checks.json` is the final report, including package versions and
per-check results. `main_rerun_checks.json` records the raw-array comparisons.
`additional_rerun_checks.json` is an earlier intermediate report: its pending
anisotropy and noise checks are completed in `full_suite_checks.json`.
`expected_tables.json` is an independent numeric snapshot of the final PDF,
including its SHA-256; it was not generated from the experiment summaries.

These checks cover experimental implementations, saved results and numerical
publication outputs. They do not verify the unchanged theoretical proofs.
Most original additional-experiment archives did not include raw checkpoints,
so those comparisons use the preserved summaries and available individual-run
records. Full reruns regenerate the missing checkpoints locally. Exact
floating-point results can vary across platforms and dependency versions.
